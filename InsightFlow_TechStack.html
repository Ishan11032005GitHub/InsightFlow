4. RAG Architecture (Dual Pipeline)

Server-side Pipeline

rag_pipeline.py

PDF → PyPDF2 (extraction) → TextCleaner → TextChunker (600 chars, 150 overlap) → SentenceTransformer embeddings → FAISS vector index → Retriever (similarity search) → Gemini LLM (answer generation)

Client-side Pipeline

pdfRagEngine.js

PDF → pdf.js (browser extraction) → Sentence-aware chunking → Custom TF-IDF vectorizer → Cosine similarity retrieval → Entity boosting → Gemini LLM (via backend proxy)

6. Key Architectural Patterns

  • State Management: React Context (DataContext, AuthContext) with localStorage persistence
  • Authentication: JWT tokens stored in localStorage, verified by authMiddleware.py
  • File Processing: Client-side (PapaParse, xlsx, pdf.js) — no server upload needed for CSV/Excel
  • Server Structure: Flask Blueprints with MVC pattern (routes → controllers → services → models)
  • SDLC Model: Incremental + Evolutionary Prototype Hybrid
  • Dual RAG: Client-side TF-IDF retrieval + Server-side FAISS/embedding pipeline
  • No-code Data Wrangling: 7 cleaning operations running entirely in-browser
